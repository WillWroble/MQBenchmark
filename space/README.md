The web version of [MQBenchmark](https://github.com/WillWroble/MQBenchmark), a no-code spatial planning benchmark built on the puzzle game Mirror Quest. Games played here are recorded anonymously and published as the human baseline in [inkling616/mqbench-human-plays](https://huggingface.co/datasets/inkling616/mqbench-human-plays).

This Space is deployed from the GitHub repository. Make changes there.
